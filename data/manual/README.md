# data/manual — elle konan dosyalar

Claude'un indiremediği veya indirmemesi gereken dosyaları buraya koyun. Ajanlar bu klasörü salt-okunur kabul eder. Dosyalar git'e girmez (bu README hariç).

| Alt klasör | Ne | Kim koyar |
|---|---|---|
| `regulation/` | Elektrik Kuvvetli Akım Tesisleri Yönetmeliği (PDF), ilgili EPDK kararları | Takım (isteğe bağlı; data-scout web'den de bulabilir) |
| `edas/` | Bir dağıtım şirketinden alınabilirse hat GIS verisi (GPKG/SHP) | Takım (pilot görüşmesinden) |
| `effis/` | EFFIS yanmış alan poligonları (veri talebiyle) | Takım (isteğe bağlı) |
| `cases/` | Hat kaynaklı yangın vakalarına dair resmi belge veya ekran görüntüsü | Takım (isteğe bağlı) |

Dosya koyduğunuzda orkestratöre tek satırla haber verin (ör. "data/manual/edas/ altına hat verisi koydum").
